INTEGER (INT) · BILANGAN BULAT Untuk Jumlah Responden & Skor Kuesioner

Dipakai untuk angka utuh tanpa koma, misalnya jumlah responden (45 orang), umur, atau skor jawaban kuesioner dari 1 sampai 5.

Contoh Penulisan di Python:
jumlah_umkm = 45
python · dasar_kuesioner.py 
# 1. Menyimpan data ke dalam wadah (Variabel)
nama_variabel = "Literasi_Keuangan"   # Teks (String)
jumlah_responden = 45                 # Angka bulat (Integer)
batas_valid = 0.70                    # Angka koma (Float)

# 2. Daftar skor 5 pertanyaan dari 1 orang responden (List)
skor_x1 = [4, 5, 4, 3, 5]

# 3. Menghitung total dan rata-rata otomatis
total_skor = sum(skor_x1)
jumlah_soal = len(skor_x1)
rata_rata = total_skor / jumlah_soal

print(f"Variabel: {nama_variabel}")
print(f"Total Skor: {total_skor} | Rata-rata: {rata_rata}")

Mengubah Jawaban Kuesioner Jadi Angka (Skala Likert)

Komputer tidak bisa menghitung kata "Setuju" atau "Sangat Setuju". Karena itu, jawaban responden diubah dulu menjadi skor 1 sampai 5.

2 TS Tidak Setuju
3 N Netral
4 S Setuju
5 SS Sangat Setuju
COBA SIMULASI JAWABAN RESPONDEN (SILAKAN KLIK)
Soal X1.1: Saya mencatat pemasukan & pengeluaran usaha tiap hari
Soal X1.2: Saya memisahkan uang pribadi dengan modal usaha
Soal X1.3: Saya menghitung keuntungan bersih setiap bulan
python · konversi_likert.py 
# Kamus perubahan teks ke angka
peta_likert = {
    "STS": 1, "TS": 2, "N": 3, "S": 4, "SS": 5
}

jawaban_teks = ["S", "SS", "N"]
skor_numerik = [peta_likert[j] for j in jawaban_teks]

print("Skor:", skor_numerik, "| Total:", sum(skor_numerik))

Panduan Praktik Langsung: Langkah demi Langkah

Ikuti urutan 4 tahap di bawah ini di laptop masing-masing. Pastikan setiap tahap berhasil sebelum lanjut ke tahap berikutnya.

TAHAP 01 · PERSIAPAN Google Colab
Siapkan Ruang Kerja Pribadi
  1. Buka link Template Notebook Panitia yang dibagikan di grup.
  2. Klik menu File (pojok kiri atas) → pilih Save a copy in Drive.
  3. Tunggu tab baru terbuka bertuliskan "Copy of...", lalu ganti judulnya menjadi NamaAnda_Pertemuan1.
  4. Klik tombol Connect di pojok kanan atas sampai muncul tanda centang hijau (RAM & Disk).
TAHAP 02 · UPLOAD FILE Dataset Excel
Masukkan File Kuesioner ke Colab
  1. Download file bahan latihan (data_kuesioner_umkm.xlsx) ke folder Downloads laptop Anda.
  2. Di Google Colab, klik ikon Folder (Files) di panel menu sebelah kiri.
  3. Klik ikon Upload to session storage (kertas dengan panah ke atas).
  4. Pilih file Excel tadi, klik Open, dan pastikan nama filenya muncul di daftar panel kiri.
TAHAP 03 · EKSEKUSI KODE Pandas Read
Baca & Tampilkan Isi Tabel Data
  1. Klik sel kode pertama berisi import pandas as pd, lalu tekan Shift + Enter.
  2. Jalankan sel kode df = pd.read_excel('data_kuesioner_umkm.xlsx', header=1) (gunakan header=1 karena baris 1 berisi judul kelompok).
  3. Jalankan df.head(10) untuk melihat 10 baris data responden pertama di layar.
  4. Pastikan tidak ada tulisan error merah dan seluruh kolom pertanyaan tampil utuh.
TAHAP 04 · AUDIT DATA Cek Struktur
Periksa Ukuran, Kolom & Kelengkapan
  1. Jalankan df.shape → catat berapa total responden (baris) dan jumlah kolomnya.
  2. Jalankan df.columns → cek apakah ada nama kolom yang typo atau spasi berlebih.
  3. Jalankan df.info() → pastikan kolom skor X dan Y terbaca sebagai angka (int64/float64).
  4. Tambahkan 1 Sel Teks (+ Text) di bagian bawah untuk menulis ringkasan temuan Anda.
Indikator Berhasil Praktik: Tabel responden muncul rapi, jumlah baris & kolom terbaca jelas, dan tidak ada pesan error merah di bawah sel kode.

MASALAH 01 Muncul FileNotFoundError?

Cek apakah file Excel sudah di-upload ke menu Folder kiri Colab, dan pastikan penulisan nama file di dalam tanda kutip persis sama.

MASALAH 02 Koneksi Terputus / Halaman Reload?

Kode Anda aman di Drive kalau sudah Save a Copy in Drive. Tinggal upload ulang file Excel-nya lalu klik Runtime → Run all.

MASALAH 03 Muncul NameError: pd is not defined?

Artinya baris import pandas as pd di bagian paling atas belum dijalankan. Jalankan dulu sel paling atas sebelum membaca file Excel.
